# kind: promo

Sell or announce an app, product, feature, launch or event. Default format `tiktok`, 15–45 s. Punchy, high energy.

- Source of truth: the product's site/app (capture stills like `tutorial.md` if there is a URL), plus facts the user gave. Every feature, price, stat or quote must come from those — never invented.
- Look = the brand: computed colors and fonts of its site; else the user's brand notes.
- Arc follows `direction.structure`; always: cover title (frame 0) → tension/benefit → proof (real UI recreated, real features) → payoff → CTA (name + domain/handle + one action).
- One idea per scene, ≤7 words on screen at a time. Use `direction.bpm` hard; land the payoff on a downbeat (or the music drop).
- Generated art (`$K/imggen.sh`): lifestyle/context scenes, abstract backgrounds, hero product-in-context only if the user supplied product photos to base it on; never fake UI or fake testimonials.
- Narration: confident, short sentences; it may skip some scenes (pure-visual beats) as long as gaps stay ≤ `checks.maxGapSeconds`.
- Caption: hook line, 2–4 short benefit lines, CTA with URL.
